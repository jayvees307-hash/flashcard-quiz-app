# Lab Reflection: Building a Flashcard Quiz App with AI Assistance

## 1. Speed and Efficiency in Prototyping
Using AI-assisted development significantly accelerated the initial setup and structure of the Flashcard Quiz application. Rather than building boilerplate HTML markup and styling Tailwind elements from scratch, I was able to generate a fully functional prototype in a single prompt. This allowed me to focus immediately on application logic, user interaction, and feature refinement.

## 2. Iterative Enhancement and Code Quality
The multi-prompt workflow demonstrated the importance of incremental progress. By breaking development into distinct phases—initial build, feature enhancements (keyboard navigation and dynamic browser title updates), and code auditing—the code remained modular and easier to debug. The auditing phase was particularly helpful for identifying edge cases, such as handling empty card states and preventing text overflow on longer flashcard content.

## 3. Key Learnings & AI Capabilities
While AI tools provide rapid generation and problem-solving, human oversight remains critical. Managing version control, handling file organization in Git, verifying edge-case logic, and ensuring proper HTML sanitization required active testing and critical evaluation. Overall, combining prompt engineering with structured Git version control provided an efficient workflow for rapid web application development.
