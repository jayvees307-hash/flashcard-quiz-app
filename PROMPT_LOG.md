> "Act as an expert frontend developer. Create a clean, interactive single-file Flashcard Quiz application using HTML, Tailwind CSS (via CDN), and JavaScript.

> - Progress tracker showing card count and completion state.
> - Simple controls: Next, Previous, and Mark as Mastered buttons.
